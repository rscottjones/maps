{{/* geo-core-v1.html — shared core for Maps / Tracks / Travelpath ============================================================= This file is copied BYTE-IDENTICALLY into every sibling plugin's layouts/partials/ directory. It is one file, copied — not several files that happen to agree. THE VERSION IS IN THE FILE NAME ON PURPOSE. Micro.blog stacks plugins as layers, and when two layers hold a file at the same path only one of them is used. An unversioned geo-core.html would therefore resolve to whichever plugin happens to sit on top, so a plugin you updated could end up running against an older sibling's stale copy. With the version in the path, every plugin always gets the core it shipped with. TO CHANGE THIS FILE: 1. copy it to geo-core-v.html and delete the old one 2. set VERSION below to N+1 3. change the partial name and the Scratch key in the shortcode ("geoCore-v") 4. do the same in every sibling plugin when you next release it Emitted once per page behind the "geoCore-v1" Scratch key: {{ if not (.Page.Scratch.Get "geoCore-v1") }} {{ .Page.Scratch.Set "geoCore-v1" true }} {{ partialCached "geo-core-v1.html" . }} {{ end }} If two plugins at different core versions are on one page, both cores are emitted and the VERSION guard below resolves it: newest wins, regardless of the order the shortcodes appear in. Contents 1. CSS — Leaflet theme overrides, dark mode, sr-only, noscript panel 2. JS — window.__geoCore: version, shapes, basemaps, createIcon, iconImg, loadOnce, ensureLeaflet, ensureCluster, loadFontAwesome, ensureLightbox, ensureVideoPlayer, registerGallery, isImageUrl / isVideoUrl / isAudioUrl plus one delegated media-click listener for the whole page. */}}
